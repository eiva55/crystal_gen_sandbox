# План разбора: DiffCSP++ на парах полиморфов (гипотеза 1, проверки 6–8)

План зафиксирован 26 октября 2026 года, до получения генераций DiffCSP++ на наборах `pairs_v1nf` и `pairs_val_v1nf`. Всё, что в разборе отличается от этого плана, помечается в отчёте как отступление, с датой и причиной. Разбор CrystaLLM-small на `pairs_v1` (K=10) проводился без такого плана, и страты сложности там выделены по наблюдаемым данным, поэтому все его результаты разведочные. Этот план нужен, чтобы результат DiffCSP++ был проверкой, а не ещё одним разведочным разбором.

## 1. Данные

| набор | часть MP-20 | структур | пар (оба n_своб ≥ 1) | составов | основная страта: пар / составов |
|---|---|---|---|---|---|
| `pairs_v1nf` | test | 251 | 129 | 94 | 59 / 51 |
| `pairs_val_v1nf` | val | 249 | 113 | 95 | 55 / 49 |
| `pairs_tv_nf` (объединение) | test и val | 500 | 242 | 189 | 114 / 100 |

Составы двух наборов не пересекаются: при сборке `pairs_val_v1` исключены 35 составов, уже вошедших в `pairs_v1`. Пара — самый низкий по энергии почти стабильный полиморф состава (энергия над выпуклой оболочкой менее 5 мэВ/атом) и один из метастабильных. Структуры, группа которых не воспроизводится при допуске 0,1 Å, исключены при сборке набора (6 в val). В наборах с суффиксом `nf` только структуры с n_своб ≥ 1: при n_своб = 0 шаблон задаёт структуру целиком.

Модель — DiffCSP++, чекпоинт `mp_csp`, условие — группа, орбиты Вайкоффа и элементы на орбитах цели. Попыток на структуру K = 10. Seed в `sample.py` не задаётся; в журнале запусков записываются коммит, образ и время.

Число структур того же типа в обучающей выборке (`n_same_type`) посчитано для всех 500 структур.

## 2. Исход

Основной исход — строгое совпадение с целью по `StructureMatcher` (0,2; 0,3; 5°). Попытка без CIF, с невалидным CIF или с другим составом считается неудачей. Вторичный исход — совпадение при стандартных допусках (0,3; 0,5; 10°).

## 3. Основной критерий (проверка 6)

**Отбор:** структуры из пар, у которых оба полиморфа имеют n_своб ≥ 1 и |Δn_своб| ≤ 2, где Δn_своб = n_своб(метастабильный) − n_своб(стабильный); объединённый набор `pairs_tv_nf`.

**Модель:** доля удачных попыток структуры как функция энергии над выпуклой оболочкой (на +10 мэВ/атом), с фиксированным эффектом состава (центрирование внутри состава) и полными контролями: ln(1 + n_гр), n_ат, n_своб, ln(1 + n_прот), ln(1 + n_тип). Стандартные ошибки кластеризованы по составу.

**Решение** (граница эквивалентности δ = 0,0216 на +10 мэВ/атом, что соответствует отношению шансов 0,917 при доле 0,5):

| результат | вывод |
|---|---|
| 90%-й ДИ целиком внутри [−0,0216; +0,0216] | при сопоставимой сложности шаблона зависимости от энергии в пределах ±0,0216 нет |
| 95%-й ДИ целиком ниже нуля | при сопоставимой сложности шаблона метастабильный полиморф воспроизводится реже; приводится оценка и ДИ |
| 95%-й ДИ целиком выше нуля | метастабильный полиморф воспроизводится чаще; приводится оценка и ДИ |
| ни одно из трёх | результат неопределённый; приводятся оценка и оба интервала |

**Ожидаемая точность.** На CrystaLLM-small в той же страте тестовой части (51 состав) стандартная ошибка около 0,015. На 100 составах ожидается около 0,010, то есть половина ширины 90%-го ДИ около 0,017. Эквивалентность будет принята, только если оценка по модулю меньше примерно 0,004. Поэтому главный результат — оценка с интервалом, а не доказательство эквивалентности.

## 4. Вторичные анализы

Заданы заранее, поправки на множественность нет, в отчёте называются вторичными.

1. Та же модель на всех парах с n_своб ≥ 1 (242 пары, 189 составов).
2. Та же модель без контролей и с контролями только n_своб и n_ат.
3. Та же модель отдельно на test и на val: согласованность знака и величины.
4. Средняя разность долей «стабильный минус метастабильный» по стратам Δn_своб > 2, |Δn_своб| ≤ 2, Δn_своб < −2; 95%-й ДИ бутстрэпом по составам (B = 3000); знаковый критерий по составам.
5. Вторичный исход (стандартные допуски) для основного критерия.
6. Основной критерий без пар, в которых хотя бы у одного полиморфа шаблон общий с другим полиморфом того же состава (`within_strata.py --exclude-degenerate analysis/results/template_degeneracy.csv`). Таких целей в `pairs_tv_nf` 56 из 500 (37 в test, 19 в val), из них 40 метастабильных: для них условие не различает полиморфы, и промах может быть следствием условия, а не модели. Если основной результат и этот вариант расходятся по выводу из таблицы раздела 3, в отчёте приводятся оба.

## 5. Замещение (проверка 8)

Каждая попытка сопоставляется со всеми полиморфами состава в MP-20 (`cross_match.py`). Сравнения те же 12, что для CrystaLLM-small (`cross_substitution.py`): доля попыток для метастабильной цели, совпавших со стабильным полиморфом, против доли попыток для стабильной цели, совпавших с другим полиморфом; от всех попыток и от промахов; строго и с учётом стандартных допусков. Поправка Холма на 12 сравнений. Отдельно перечисляются цели, у которых шаблон совпадает с шаблоном другого полиморфа состава (`template_degeneracy.csv`): для них совпадение с другим полиморфом не ошибка модели, а следствие условия, и они разбираются отдельно.

## 6. Сравнение с CrystaLLM-small (разведочно)

На тех же структурах test есть генерации CrystaLLM-small с группой в запросе (K = 10); для val они будут получены с seed 1337. Сравнивается оценка основного критерия двух моделей на одних и тех же структурах. Различие условий (полный шаблон против символа группы) делает это сравнение описательным.

## 7. Что не меняется после получения данных

- Пороги страт (2 свободные координаты), граница эквивалентности, допуски `StructureMatcher` и набор контролей.
- Состав наборов: цели не исключаются по результатам генерации.
- Основной исход и основной отбор.

## 8. Команды разбора

```bash
python analysis/combine_sets.py --dst pairs_tv_nf --src pairs_v1nf pairs_val_v1nf
python analysis/cross_match.py --set pairs_tv_nf \
  --bench-dir "outputs/bench/pairs_v1nf_k10_c??" "outputs/bench/pairs_val_v1nf_k10_c??" \
  --out analysis/results/cross_pairs_tv_nf_diffcsp_k10.csv > analysis/results/cross_pairs_tv_nf_diffcsp_k10.txt
python analysis/analyze_pairs_v1.py --set pairs_tv_nf --label diffcsp_tv_k10 \
  --eval "outputs/bench/pairs_v1nf_k10_c??/eval.csv" "outputs/bench/pairs_val_v1nf_k10_c??/eval.csv" \
  --cross analysis/results/cross_pairs_tv_nf_diffcsp_k10.csv > analysis/results/analyze_pairs_diffcsp_tv_k10.txt
python analysis/within_strata.py --label diffcsp_tv_k10 > analysis/results/within_strata_diffcsp_tv_k10.txt
python analysis/within_strata.py --label diffcsp_tv_k10 --exclude-degenerate analysis/results/template_degeneracy.csv \
  > analysis/results/within_strata_diffcsp_tv_k10_nodeg.txt
python analysis/cross_substitution.py analysis/results/cross_pairs_tv_nf_diffcsp_k10.csv > analysis/results/cross_substitution_diffcsp_tv_k10.txt
```

Основной результат — строка «сопоставимые |Δn| <= 2, оба n_free >= 1 (основной критерий проверки 6)», вариант «полные контроли», в `within_strata_diffcsp_tv_k10.txt`. Цепочка проверена на искусственных исходах с заложенным наклоном −0,020 на +10 мэВ/атом: получено −0,022 [−0,031; −0,014].
